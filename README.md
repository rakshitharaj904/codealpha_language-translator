# Language Translation Tool

## Project Overview

This project is a Python-based Language Translation Tool developed as part of the CodeAlpha AI Internship.

The application allows users to enter text, select a source language and target language, and translate the text using the Sarvam AI translation API.

## Features

- Translate text between multiple Indian languages
- Source language selection
- Target language selection
- Clear input and output
- Copy translated text
- Simple and user-friendly GUI
- Uses Sarvam AI API for translation

## Supported Languages

- English
- Hindi
- Kannada
- Tamil
- Telugu
- Malayalam
- Bengali
- Marathi
- Gujarati

## Technologies Used

- Python
- Tkinter
- Sarvam AI API
